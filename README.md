# Campus Resource Booking & Conflict Management System

A DBMS-based web application for managing and booking campus resources such as classrooms, laboratories, seminar halls, and equipment.

## Project Status

🚧 Under Development

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: MySQL
- Version Control: Git & GitHub

## Core Features

- User authentication
- Resource management
- Resource availability checking
- Booking management
- Booking conflict detection
- Booking approval workflow
- Maintenance tracking
- Usage history
- Admin dashboard
